# Hatchery Wiki

**Classic Pixelmon Day Care breeding — the OldSchool ranch-style loop, rebuilt
and fully configurable.**

Hatchery is an open-source Bukkit plugin for **Pixelmon on Arclight**. The
current server-tested line targets **Minecraft 1.21.1 / Pixelmon 9.3.x** and
recreates pre-modern, ranch-block-era Pixelmon breeding on top of modern
Pixelmon **Day Care** blocks: place a Day Care, add a compatible pair, shape
the **environment** around it for speed, and collect the egg from a GUI.

## TL;DR

1. Place a Pixelmon **Day Care** block → it becomes your daycare.
2. Right-click → GUI → add a **compatible** party pair (egg group + gender +
   species/Ditto, discovered only).
3. Each tick, blocks around it score **environment points** weighted by the
   pair's **types** → a **satisfaction tier** with a speed multiplier.
4. Progress fills → **collect the egg** from the GUI.
5. **Hourglasses** fast-forward ticks; the **Upgrade** item widens the radius.

The 1.21.1 build also includes duplicate-protection around Pixelmon party
storage and clears held items from generated eggs.
